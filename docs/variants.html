Add a Variant

Step-by-step guide to extending Moddable Chess with a new variant.

1. Register the variant

If your variant uses a non-standard board, add it to VARIANT_BOARDS in chess-engine.js:

const VARIANT_BOARDS = {
  capablanca: { rows: 8, cols: 10, fen: '...' },
  yourVariant: { rows: 8, cols: 8, fen: '...' },
};

For 8×8 variants with standard starting position, you don't need an entry here — just use the variant key in createGame.

2. Add rule modifications

Open chess-variants.js. There are three places to hook in:

a) Win condition (getVariantStatus)

If your variant has an alternate win condition:

if (v === 'yourVariant') {
  // Check for your custom win condition
  if (someCondition) return 'yourVariant-w'; // white wins
}

b) Move filtering (variantLegalMoves)

If your variant restricts available moves:

if (v === 'yourVariant') {
  // Filter moves — e.g., forced captures
  const captures = moves.filter(m => g.board[m.to]);
  if (captures.length > 0) moves = captures;
}

c) Move execution (chess-play.js)

If your variant changes how moves are executed (e.g., pieces don't move on capture in Rifle Chess), modify makeMove. Always save state in the undo object for proper reversal.

3. Add new piece types (optional)

If your variant introduces new pieces:

  • Add the piece character to MCE.PIECE in chess-engine.js
  • Add movement generation in chess-moves.js (in the main piece-type switch)
  • Add attack detection in the attacks() function
  • Add SVG sprites to assets/pieces.svg

4. Add to the game controller

In game-controller.js, add your variant to the picker array and the DESCRIPTIONS object:

['yourVariant', 'Your Variant Name'],

5. Handle special starting positions

If your variant has a non-standard starting FEN (like Racing Kings), add it in the startGame function:

if (variant === 'yourVariant') {
  MCE.loadFEN(game, 'your/custom/fen w - - 0 1');
}

Example: Adding "Los Alamos" variant

Los Alamos Chess uses a 6×6 board with no bishops, no castling, and no double pawn step. The first chess game ever played by a computer (1956).

// 1. In VARIANT_BOARDS (chess-engine.js):
losAlamos: { rows: 6, cols: 6, fen: 'rnqknr/pppppp/6/6/PPPPPP/RNQKNR w - - 0 1' },

// 2. In createVariantGame (chess-engine.js):
if (variant === 'losAlamos') { g.noCastling = true; g.noEnPassant = true; }

// 3. In VARIANTS (chess-variants.js):
losAlamos: { label: 'Los Alamos' },

// 4. In DESCRIPTIONS + VARIANT_GROUPS (game-controller.js):
losAlamos: { title: 'Los Alamos Chess', text: '...', rule: 'Board: 6×6 · Win: Checkmate' },

Example: Adding a rule-only variant

Single-Check wins on the first check delivered. It reuses Three-Check's check counter but with a threshold of 1.

// 1. No VARIANT_BOARDS entry needed (standard 8×8 position)

// 2. In VARIANTS (chess-variants.js):
singleCheck: { label: 'Single-Check' },

// 3. In getVariantStatus (chess-variants.js):
if (v === 'singleCheck') {
  if (g.checkCount.w >= 1) return 'checkmate';
  if (g.checkCount.b >= 1) return 'checkmate';
}

Testing

After adding your variant:

  • Select it in the variant picker at /play/
  • Verify the starting position renders correctly
  • Test that legal moves are generated properly
  • Test the win condition by playing to completion
  • Test that undo works (the engine uses make/unmake for legality checking)

Board geometry limitations

Moddable Chess supports rectangular boards only (from 5×5 up to 12×12). Hex-board, circular, and other non-rectangular geometries require a fundamentally different renderer and coordinate system.

For hex-board games (Hexagonal Chess, Glinski, etc.), see the sister project Moddable Hexmaps — a dedicated engine for hexagonal grids.
