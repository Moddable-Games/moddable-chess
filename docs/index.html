Quick Start

Include the engine scripts in your HTML (order matters):

<script src="js/chess-engine.js"></script>
<script src="js/chess-moves.js"></script>
<script src="js/chess-play.js"></script>
<script src="js/chess-variants.js"></script>
<script src="js/board-renderer.js"></script>

Create a game and render it:

const game = MCE.createGame('standard');
MCE.renderBoard(document.getElementById('board'), game, {
  size: 480,
  onSquareClick: (sq) => { /* handle click */ }
});

Architecture

The engine is split into focused modules that extend the global MCE namespace:

FileExportsPurpose
chess-engine.jsMCE coreBoard state, FEN, coordinate helpers, game creation
chess-moves.jspseudoLegalMoves, legalMoves, inCheckMove generation for all piece types
chess-play.jsmakeMove, unmakeMove, getStatusMove execution, undo, game state and draw detection (threefold repetition, insufficient material, 50-move rule)
chess-variants.jsVARIANTS, getVariantStatus, variantLegalMovesVariant-specific rule overrides
board-renderer.jsrenderBoardSVG board rendering with click handling

Board Representation

The board is a flat array of size rows × cols. Index 0 is the top-left square (a8 in standard chess). Pieces are single characters — uppercase for White, lowercase for Black:

CharPieceVariants
P/pPawnAll
N/nKnightAll
B/bBishopAll
R/rRookAll
Q/qQueenAll
K/kKingAll
A/aArchbishop (B+N)Capablanca, Grand
C/cChancellor (R+N)Capablanca, Grand
S/sSage (1-step any direction)Courier
M/mMaharaja (Q+N compound)Maharaja, Amazon Chess

Variable Board Sizes

The engine supports arbitrary rectangular boards. Each game object has rows and cols properties. All coordinate functions accept an optional game context:

MCE.sq(row, col, game)  // → index
MCE.rc(index, game)    // → [row, col]
MCE.onBoard(row, col, game) // → boolean
