FOR DEVELOPERS

Five lines to a playable board.

Load the scripts, create a game, render the board. The engine handles move generation, check detection, variant rules, and board rendering.

const game = MCE.createGame('standard');
const moves = MCE.legalMoves(game);
MCE.makeMove(game, moves[0]);
const status = MCE.getStatus(game);
MCE.renderBoard(el, game, { size: 480 });
